Having trouble installing a downloaded CRX?

Ungoogled Chromium

Open chrome://flags/#extension-mime-request-handling and set Handling of extension MIME type requests to Always prompt for install, then relaunch. If that flag is missing, open chrome://extensions, enable Developer mode, and drag the downloaded .crx file onto the page.

Chromium or Google Chrome

Try enabling Developer mode at chrome://extensions and dragging the file onto that page. Some browser builds, operating systems, or managed-device policies block local CRX installs regardless of the flag; in that case open the listing and use the browser's supported installation method.

“Invalid package” or no prompt

Right-click the download link and choose Save link as, then retry from the local file. Confirm the file is not zero bytes and that your connection or proxy did not replace the response with an error page.

Search returns no listings

The Store is a JavaScript-heavy site and changes often. Try a shorter search, check your connection/proxy, or open the official Chrome Web Store. CWS Lite doesn't try to bypass login pages or anti-bot challenges.

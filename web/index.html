Trouble installing a download?

Chrome Web Store (.crx)

Ungoogled Chromium: open chrome://flags/#extension-mime-request-handling, set Handling of extension MIME type requests to Always prompt for install, then relaunch. If the flag is missing, open chrome://extensions, enable Developer mode and drag the .crx file onto the page.

Chromium / Chrome: try Developer mode and drag-and-drop. Some builds and managed devices block local CRX installs; use the listing page instead.

Firefox Add-ons (.xpi)

Firefox should offer to install right after clicking the link. If it only saves the file, open about:addons, click the gear icon and choose Install Add-on From File…. Packages are the original signed files from addons.mozilla.org.

Invalid package, or no prompt

Right-click the link and choose Save link as, then retry from the local file. Make sure the file is not zero bytes and that a proxy did not replace it with an error page.

No results

The Chrome Web Store changes often and does not offer a public API, so its listings are read from page HTML. Try a shorter search or check your connection. CWS Lite does not try to get around logins or anti-bot checks.
